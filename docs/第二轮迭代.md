# 第二轮：事件归并与证据回溯

日期：2026-10-12。

本轮已实现：

- GPT可明确选择候选事件ID，给出同一交易理由及逐字引用。程序独立核对候选存在性、主体、交易对象、交易批次、引用是否存在；不能仅凭模型给出的ID强制合并。
- 公司法定后缀规范化；非后缀类简称仅接受已核对的一手原文中的明确简称定义。相同双方的不同交易标识保持分开，展示待复核提示。
- 业务阶段按已知发生时间优先排序，披露时间仍单独保存；晚到旧材料不能把较晚的审批阶段退回签约。缺少可比较时间时保守保留阶段。
- 当前版本展示“当前已发现的最早披露”，不使用后来才导入的材料污染旧版本，不声称全网首发。
- 否认/更正与受影响陈述并排展示；版本时间线显示具体新增说法、旧状态→新状态与阶段变化。
- 历史快照有醒目标识与返回当前版本按钮；写入口令有独立入口，避免用户在通知抽屉中寻找。
- 云端一次性验收脚本：通过CLOUD_SMOKE_RUN指定批次，同一批次由PostgreSQL主键保证只执行一次。记录数据库、未授权写入、真实GPT、iFinD、版本/通知/去重；结果写入verification_runs及脱敏日志。不开公网域名。

本地验证：52项测试通过，TypeScript和生产构建通过。浏览器已验证V1只显示最初2条传闻/预测，V5显示更正/过期；版本差异和来源按钮可操作。

云端结果须以最新CLOUD_SMOKE_RESULT为准，不能把本地验证或模型列表接口认证成功算作完整抽取通过。旧的初次网络失败任务保留作为恢复验证依据。
