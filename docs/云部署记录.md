## 配置

- 仓库 `yjnq/investment-evidence`，main自动部署；启用Wait for CI。
- `investment-evidence` Web服务，`Postgres`数据库及持久卷。
- `DATABASE_URL`使用平台内部引用，不复制数据库密码。
- GPT、iFinD密钥经用户明确授权保存到服务私密环境变量。写入访问口令单独随机生成，本机副本在被Git忽略的 `.data/cloud-access.txt`。
- 临时密钥转存文件已经删除，剪贴板已清理。没有密钥进入源码、聊天或日志。
- Dockerfile自动检测构建；健康检查 `/api/workspace`。新项目不能依赖旧Railway Config-as-code，实际部署参数在控制台配置。
- `CLOUD_SMOKE_RUN`为一次性验收批次标识；同一批次重部署不会重新调用接口。
- 使用现有试用额度，未选择付费升级。

## 云端发现并解决的问题

1. 原模型HTTP 8080入口在云端连接超时。同供应商HTTPS入口认证返回200并确认目标模型存在，云端已改为HTTPS，后续真实抽取成功。
2. iFinD业务码1的data可能是Markdown“本次新闻搜索结果为空”，不是JSON数组。旧版误判为接口解析失败。现仅识别这个明确消息族为空集合，同时支持完整JSON代码围栏；未知错误、权限说明、截断JSON仍拒绝，不能静默当成无数据。
3. 原检索词过长时上游返回无结果。缩短为“国泰君安 海通证券”后云端返回5条候选。空结果不代表事件不存在。
4. 网页终端WebSocket会断开，改为仓库内一次性验收脚本，在容器健康后执行并记录到数据库及日志，避免将未执行的终端命令视为已测试。
