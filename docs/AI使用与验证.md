# AI 使用与验证记录

## 开发协作

用户提供笔试题与已确认交接框架；Codex编写事件规则、服务端、React页面、测试及部署配置。Codex执行命令、接口检查和浏览器操作，修正同源误拦截、时区边界、引用定位、来源核验标记等问题。用户指定复用OpenCode中的第三方GPT服务，并提供GitHub仓库地址。

没有使用多Agent集群。未把原始文档中的指令当作额外用户授权。没有将金融密钥、模型密钥复制进项目文件。

## 产品内真实模型调用

模型配置名称：`gpt-5.6-sol`；第三方OpenAI兼容平台，复用用户已有OpenCode配置。名称由供应商配置提供，不能独立证明底层模型身份。

接口采用 Chat Completions JSON Schema 结构化输出；本机已实测兼容。官方文档抓取当时返回403，未据此宣称当前所有OpenAI模型或第三方模型都支持相同参数。云端和其他供应商需要独立验证。

## 人工夹具与真实AI的区别

测试沙盒的示例科技/示例芯片、示例软件均为虚构，抽取结果为人工写入夹具，不调用模型。它们用于稳定验证否认、更正、过期、去重与通知，不能计入真实模型准确率。

8项模型接口测试使用mock响应，只证明异常处理与格式边界。尚未完成20–30条分类和15–20对同一/不同事件的人工标注评测，因此不报告准确率。
