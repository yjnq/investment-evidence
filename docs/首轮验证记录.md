## 浏览器实测

在 Codex 内置浏览器打开 localhost 并实际操作：

- 从空状态点击传闻 → 关注 → 部分否认 → 正式进展。
- 浏览真实 GPT 结果，核对5条监管批复陈述及单位和条件。
- 刷新后仍能看到事件与版本；金额更正、过期后显示V5。
- 历史时间线显示每版新增陈述数量与状态变化数量，可打开旧结论。
- 窄窗口下界面改为上下布局，列表横向滚动。已检查截图；未做全面移动设备矩阵。

发现并修复：Next 开发代理的 req.url 使用 localhost、浏览器使用127.0.0.1，原来源校验误拦截。修复为开发时按 Host 校验；部署可设置明确 APP_ORIGIN。

发现并修复：引用按钮先切换来源页再定位元素，原先定位发生在DOM挂载前；改为面板更新后的 effect 定位。

发现并修复：日期级有效期原来按UTC午夜判断；改为上海时区当日结束。
