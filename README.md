# 知序 · 投资事件证据工作台

面向跟踪自选股重大事项的个人研究用户，把“某条新闻说了什么”组织为“同一交易目前有什么依据、哪些判断发生了变化”。首版聚焦并购重组，当前已完成第二轮功能与私有云链路验收，**按用户要求暂不开放公网，最终视频与提交验收尚未完成**。

## 已实现

- Next.js / React / TypeScript 页面：事件列表、材料导入、陈述级证据、版本时间线、原始材料、处理记录、关注与站内通知。
- GPT 兼容接口真实抽取；引用逐字存在性、实体出现性、字段结构校验。模型异常保留材料与失败任务，不发布新版本。可重试。
- 事实性陈述、观点、推测、传闻与核验状态分开。公司/监管来源需操作人确认已核对原文，才参与一手披露确认。
- 主体 + 交易对象 + 交易标识匹配；模型可参考现有候选的标识。不确定保持分开。以陈述键精确表达反驳和更正。
- 材料指纹去重、同链接修订关联、转载来源分组、不可变历史快照、期限检查、关注后通知。
- 事务持久化：部署使用 PostgreSQL + Drizzle；没有 DATABASE_URL 时，本地开发使用磁盘 PGlite（PostgreSQL WASM）进行验证，数据在 `.data/evidence`。
- 明确标注的虚构测试回放与一份已核验的证监会真实公开材料。回放人工标注数据，绝不冒充模型结果。

## 本地启动

要求 Node.js 22+。

```bash
npm ci
cp .env.example .env.local
npm run dev
```

打开 <http://127.0.0.1:3000>。未配置模型也能运行构造测试沙盒。模型调用需要配置以下服务端变量：

```dotenv
MODEL_BASE_URL=https://你的兼容接口/v1
MODEL_NAME=你的模型名称
MODEL_API_KEY=你的密钥
```

也可设置 `OPENCODE_CONFIG_PATH` 指向已有 OpenCode JSON 配置。本地服务只读取对应 provider 的 baseURL、apiKey 与模型名，不复制密钥到项目。环境文件、数据库、依赖和构建产物均已忽略。**不要提交个人 OpenCode 配置**。

生产部署必须设置 `DATABASE_URL`、`APP_ACCESS_TOKEN` 和模型配置。访问口令在工作台顶栏“设置写入口令”中输入，只保存在当前页面内存。整个工作空间是单一演示用户共享的数据，尚未实现账户隔离。

## 最短操作路径

1. 点击“1 传闻”，建立虚构测试事件。
2. 点击“关注变化”。依次点击“2 否认”“3 进展”“4 更正”。
3. 在证据中查看被反驳的旧说法与更正金额；切换“版本时间线”，检查历史版本未被改写。
4. 查看通知，再次点击同一测试步骤，不会增加版本或通知。
5. 点击“5 不同交易”，确认不同交易对象保持分开；点击“查过期”，确认只是特定预测失效，业务阶段不变。
6. 点击“接入新材料”，提交新原文，实际调用模型。处理记录可查看失败状态与重试。

真实材料导入：`node scripts/import-case.mjs`。模型测试（虚构材料，实际调用模型）：`node scripts/smoke-api.mjs`。二者会创建数据并消耗接口额度，请在开发服务器启动且模型已配置后执行。

## 数据与 AI 分工

来源材料保存标题、机构、链接、内容、发生日期、披露日期、导入时间、来源更新时间及指纹。版本形成时间是系统更新时间。未知时间留空；日期级精度不补造秒数。历史快照只使用当时已经处理的材料。

模型负责抽取陈述、类型、引用、交易身份与候选对应关系；程序负责结构/原文校验、状态规则、快照、事务及通知。模型没有联网、任意 URL 抓取或工具执行能力；原文被当作不可信数据，不能改变系统指令。React 以文本显示输入，不执行 HTML。

真实案例选取国泰君安吸收合并海通证券，材料及验证见 [真实案例核验](docs/真实案例核验.md)。iFinD 返回仅用于候选发现：片段有截断、说明性文字且缺原文 URL，不能一律当一手证据。此前扶摇验证数据尚未接入产品卡片。

## 已知边界与未做事项

- 源码已推送至 https://github.com/yjnq/investment-evidence 。未完成公网运行 URL、60–180 秒视频；云 PostgreSQL 与接口验收已通过。
- iFinD 在线公告候选检索已接入；扶摇行情背景卡片、更多真实阶段材料仍待迭代。
- 同一事件以模型辅助的稳定文本标识匹配，尚无实体别名库、语义相似度二次仲裁、人工拆分台。可能漏合并；交易标识错误也可能误合并。
- 引用存在不等于引用充分支持结论。模型仍可能遗漏否定、条件或误分类；来源身份和关键演示结论需要人工核验。
- 来源核对是操作人声明，不是平台认证或密码学验真；一手披露也可能更正。缺披露时间的旧材料不会随意推进已有阶段。
- 版本和陈述作为事件 JSON 快照存储，材料、事件、任务、通知独立表；全工作空间事务串行化适合小型演示，未做大规模检索和并发性能优化。
- 限流为单进程全局20次写入/分钟，当前使用单实例，公开前建议在平台网关加限流；不支持多租户，不向公众开放无口令写入。
- 过期为手动检查，不是后台定时扫描。请求中断后的任务在同材料重试时恢复，没有独立作业队列。
- URL 仅用作出处链接，不由服务器抓取；不接收文件上传。没有研报全文、全网首发证明、自动交易和股价因果推断。

所有内容用于事件研究与证据管理，不构成投资建议。

第二轮已加入显式候选匹配与依据校验、保守简称识别、具体版本差异、否认/更正证据对照、最早已知来源和历史快照提示，见 [第二轮迭代](docs/第二轮迭代.md)。

私有云验收：设置唯一 `CLOUD_SMOKE_RUN` 批次后重部署，启动脚本在应用健康后执行一次端到端检查，结果写入 PostgreSQL `verification_runs` 与 `CLOUD_SMOKE_RESULT` 日志。该操作会调用模型/iFinD并创建标注清楚的测试数据；同一批次不会重复执行。用户当前要求服务暂不公开。

最终私有云验收5项通过，iFinD实际返回5条候选；报告见 [云部署记录](docs/云部署记录.md)。本地累计58项测试通过。
